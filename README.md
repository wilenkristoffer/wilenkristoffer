### Hi, I'm Kristoffer

Fullstack developer in Stockholm. Most of my work is putting LLMs into real systems, and keeping the rules that matter in code instead of in the prompt.

What's public here is what I build on my own time, mostly local AI: things that run on my own GPU instead of calling an API.

- **[LokalProtokoll](https://github.com/wilenkristoffer/LokalProtokoll)** records a meeting, works out who said what, and writes minutes with a local LLM. Then it checks the minutes against the transcript before you share them.
- **[Nosey](https://github.com/wilenkristoffer/Nosey)** is a small character in the corner of the screen that looks at whatever window you switch to and has an opinion about it.
- **[llm-inference-optimization-lab](https://github.com/wilenkristoffer/llm-inference-optimization-lab)** is where I measure how LLM serving actually behaves on an AMD RX 7800 XT, with Ollama and vLLM on ROCm.
- **[Vocare](https://github.com/wilenkristoffer/Vocare)** is a voice and text assistant with RAG on pgvector and tools through an MCP server.
- **[repo-city-vr](https://github.com/wilenkristoffer/repo-city-vr)** turns a git repo into a city you can walk around in VR. The people on the street talk through Ollama.

At work I build LLM agents, integrations and web apps, mostly in TypeScript, Python and C#/.NET.
